建议检查
    连接不上？查看常见配置错误 服务地址、网络、身份验证与权限排查
    Endpoint URL

    建议填写包含协议的完整服务地址；裸域名会自动补全 HTTPS，阿里云原生服务域也会升级为对应的 S3 兼容地址。

    DNS / TLS

    确认运行 EasyBackup 的主机能解析 Endpoint，并能通过 443 端口建立 TLS 连接；代理和自签名证书也可能拦截请求。

    Bucket / Region

    Bucket 只填写名称，不要带 s3://；Region 必须与 Bucket 所在地域一致，例如上海为 cn-shanghai。

    凭据与权限

    确认所选凭据配置存在且 AK/SK 有效，并允许在目标前缀执行写入、读取、读取元数据和删除对象。

    签名与系统时间

    签名不匹配通常由错误的 AK/SK、Region、Endpoint 或主机时间偏差引起；请先同步系统时间后重试。

    PublicEndpointForbidden

    阿里云禁止默认公网 Endpoint 时，请使用绑定到 Bucket 的自定义 CNAME；同地域云主机也可改用内网 Endpoint。

    SFTP 主机密钥

    首次连接或服务器密钥变更时，请向管理员线下核验 SHA256:... 指纹。不要在未核验时绕过主机身份检查。

    SFTP 认证

    确认凭据类型为 SFTP、用户名正确，并按服务器要求配置密码或完整私钥；加密私钥还需要正确的 Passphrase。

    SFTP 目录与配额

    确认远端根目录可创建，且账号具有列出、写入、读取、重命名和删除权限，同时检查服务器剩余空间与磁盘配额。
